# وكيل الذكاء الاصطناعي العربي (Aziz29484/320)

هذا المشروع هو وكيل ذكاء اصطناعي تفاعلي تم تطويره باستخدام Gradio ومكتبة Hugging Face `transformers`.

## 🚀 الحالة الحالية

تم تبسيط المشروع لضمان أقصى قدر من الاستقرار على مساحات Hugging Face المجانية.

| الميزة | التفاصيل |
| :--- | :--- |
| **النموذج الأساسي** | Qwen-0.5B-Chat |
| **تحسين الأداء** | تم استخدام تقنية الكمّ (4-bit Quantization) لتقليل استهلاك الذاكرة. |
| **اللغة المدعومة** | اللغة العربية (بشكل أفضل بكثير من النماذج الصغيرة الأخرى). |
| **الواجهة** | Gradio ChatInterface مبسطة. |
| **الاستقرار** | يتضمن آلية احتياطية (Fallback) للتحول إلى `distilgpt2` في حال فشل تحميل Qwen بسبب قيود الموارد. |

## 💡 تجاوز قيود الموارد (Google Colab)

للتغلب على قيود الذاكرة والوصول إلى نماذج أكبر وأكثر قوة، قمنا بتوفير ملف **`app_colab.ipynb`**.

يمكنك تشغيل هذا الملف على Google Colab للاستفادة من موارد الحوسبة الأكبر وتشغيل نماذج مثل Qwen-1.8B-Chat أو غيرها، مع واجهة Gradio يمكن الوصول إليها عبر رابط عام.

## ⚙️ الملفات الرئيسية

*   **`app.py`**: ملف التطبيق الرئيسي الذي يقوم بتحميل النموذج (Qwen-0.5B-Chat) وتشغيل واجهة Gradio.
*   **`requirements.txt`**: قائمة بالاعتماديات المطلوبة (gradio, torch, transformers, accelerate, bitsandbytes).
*   **`app_colab.ipynb`**: دفتر ملاحظات Google Colab لتشغيل الوكيل على موارد خارجية.
